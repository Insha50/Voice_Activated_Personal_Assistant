# 🎙️ Voice-Activated Personal Assistant in Python

## 📌 Project Overview
This project is a voice-controlled personal assistant built using Python. It listens to your voice, responds with speech, searches Wikipedia, opens websites, and even sends emails — all through natural voice interaction.

## 🧠 Key Features
- 🔊 **Text-to-Speech**: Converts responses into spoken audio using `pyttsx3`
- 🎤 **Speech Recognition**: Captures and interprets voice commands using `speech_recognition`
- 📚 **Wikipedia Automation**: Searches and summarizes topics using `wikipedia` API
- 🌐 **Web Automation**: Opens websites like YouTube, Gmail, Google, LinkedIn, and LeetCode
- 📧 **Email Sending**: Sends emails via SMTP using voice input
- 🕒 **Time Reporting**: Tells the current time on request
- 🙋‍♀️ **Personalized Greetings**: Greets the user based on time of day

## 🛠 Technologies Used
- `pyttsx3` – Text-to-speech engine
- `speech_recognition` – Voice input processing
- `wikipedia` – API for automated summaries
- `webbrowser` – Opens URLs via voice
- `smtplib` – Sends emails securely
- `datetime`, `os` – System-level operations
